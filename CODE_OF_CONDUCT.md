# Code of Conduct

Participants should communicate respectfully, welcome different experiences, and focus criticism on ideas and code. Harassment, threats, discriminatory language, doxxing, and sharing private data are unacceptable.

Maintainers may edit or remove harmful content, lock discussions, or restrict participation proportionately. They should explain decisions when doing so does not expose private information. Good-faith disagreement is welcome.

Report conduct concerns privately to **eyupcanbilgin01@gmail.com**. Include only the information necessary to understand the concern. The maintainer will handle reports discreetly and avoid disclosing reporter identities without consent unless required by law. Do not disclose sensitive personal details in a public issue.
