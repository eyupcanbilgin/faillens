# Security policy

Version 0.1.x is the initial supported line. Maintainer: [eyupcanbilgin](https://github.com/eyupcanbilgin). No guaranteed security response SLA is promised.

Report vulnerabilities privately to **eyupcanbilgin01@gmail.com**. Once the repository is public and private vulnerability reporting is enabled, you can also use [GitHub's private reporting form](https://github.com/eyupcanbilgin/faillens/security/advisories/new). Do not post exploit details, credentials, production reports, or customer data in public issues.

Include affected version, a minimal synthetic reproduction, impact, and suggested mitigation if available. Do not probe systems you do not own or have permission to test.

See [the threat model](docs/security.md) for prompt injection, redaction limits, provider exposure, artifact handling and telemetry. Enabling private vulnerability reporting is required by [the launch checklist](docs/launch.md).
