# Changelog

## 0.1.0 — Initial release candidate

- Playwright JSON adapter with stable per-failure evidence IDs and bounded input.
- Optional inline collector for page network failures and console errors.
- Deterministic product, test, environment, retry-recovery and unknown hypotheses.
- Common-secret and PII redaction before output and provider calls.
- Optional OpenAI structured reasoning with no tools, bounded calls, validated references and explicit fallback.
- Console, Markdown and JSON output; no browser or API key needed for the fixture demo.
- Curated evaluation, fake-provider tests, privacy/security fixtures and real browser demo.
- Opt-in OpenTelemetry, read-only CI integration, npm package smoke verification and bilingual README.

Unpublished. See [release notes](docs/release-v0.1.0.md) and [launch checklist](docs/launch.md).
